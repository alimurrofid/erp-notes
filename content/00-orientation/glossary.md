# Glossary

## Definition

Daftar istilah yang dipakai lintas modul, ditulis sebelum pembaca menemukannya di artikel. Definisi di sini ringkas dan konsisten dengan artikel kanonik; jika berbeda, artikel kanonik yang berlaku.

## Accounting

| Istilah | Definisi |
|---|---|
| **COA (Chart of Accounts)** | Daftar terstruktur akun pembukuan. Satu COA kanonik ada di [[02-accounting/chart-of-accounts|Chart of Accounts]]. |
| **General Ledger (GL)** | Buku besar utama tempat seluruh jurnal terposting dan menjadi dasar laporan keuangan. |
| **Subledger** | Buku pembantu per modul (AR, AP, persediaan, aset) yang menjadi sumber jurnal ke GL. |
| **Journal Entry** | Catatan debit-kredit yang seimbang untuk satu peristiwa ekonomi. |
| **Accrual** | Pengakuan pendapatan/beban pada periode terjadinya, bukan saat kas berpindah. |
| **COGS** | Harga pokok penjualan; biaya yang diakui bersamaan dengan pendapatan. |
| **WIP (Work in Process)** | Akun perantara untuk biaya produksi/proyek yang belum menjadi barang jadi atau belum diakui sebagai HPP. |
| **GR/IR** | Akun kliring antara penerimaan barang dan tagihan vendor; bukan provisi. |
| **ECL** | Expected Credit Loss; estimasi kerugian piutang berdasarkan IFRS 9. |
| **NRV** | Net Realizable Value; harga jual dikurangi biaya penyelesaian dan penjualan. |
| **ETR** | Effective Tax Rate; beban pajak dibagi laba sebelum pajak. |
| **DSO** | Days Sales Outstanding; rata-rata hari piutang tertagih. |

## Tax (Indonesia)

| Istilah | Definisi |
|---|---|
| **PPN** | Pajak Pertambahan Nilai. Tarif dan DPP mengikuti [[11-tax/vat-fundamentals|VAT Fundamentals]]. |
| **PPh** | Pajak Penghasilan; dapat bersifat final atau tidak final. |
| **DPP** | Dasar Pengenaan Pajak. |
| **Faktur Pajak** | Dokumen bukti pungutan PPN; sejak Coretax diterbitkan elektronik. |
| **Withholding Tax** | Pemotongan PPh pihak ketiga atas jasa, sewa, atau penghasilan tertentu. |
| **e-Bupot** | Bukti pemotongan/pemungutan unifikasi elektronik. |

## Sales and Purchasing

| Istilah | Definisi |
|---|---|
| **O2C (Order to Cash)** | Rangkaian quotation → order → delivery → invoice → payment → return. |
| **P2P (Procure to Pay)** | Rangkaian PR → RFQ → PO → receipt → match → bill → payment → return. |
| **ATP (Available to Promise)** | Kuantitas yang dapat dijanjikan ke pelanggan setelah memperhitungkan stok dan komitmen. |
| **3-Way Match** | Pencocokan PO, penerimaan barang, dan tagihan vendor sebelum pembayaran. |
| **Landed Cost** | Biaya tambahan (freight, bea, asuransi) yang dikapitalisasi ke nilai persediaan. |
| **Contract Liability** | Kewajiban mengirim barang/jasa karena pelanggan sudah membayar di muka. |
| **Performance Obligation** | Janji dalam kontrak untuk menyerahkan barang/jasa yang dapat berdiri sendiri (IFRS 15). |
| **BAST** | Berita Acara Serah Terima; titik pengalihan kontrol pada proyek. |

## Inventory and Manufacturing

| Istilah | Definisi |
|---|---|
| **UOM** | Unit of Measure; satuan dan faktor konversinya. |
| **Lot / Serial** | Penanda kelompok atau unit individual untuk ketertelusuran. |
| **Cycle Count** | Penghitungan stok berkala per area, bukan menghitung seluruh gudang sekaligus. |
| **BOM (Bill of Materials)** | Daftar komponen dan kuantitas untuk membuat satu produk. |
| **Routing** | Urutan operasi dan work center yang dibutuhkan untuk memproduksi item. |
| **Work Center** | Pusat kerja dengan kapasitas, tarif, dan jam operasi. |
| **MRP** | Material Requirements Planning; perhitungan kebutuhan berdasarkan BOM, stok, dan jadwal. |
| **MO (Manufacturing Order)** | Perintah produksi untuk sejumlah item pada tanggal tertentu. |
| **Backflush** | Pengurangan komponen otomatis saat produksi dilaporkan, bukan lewat pengeluaran manual. |
| **OEE** | Overall Equipment Effectiveness; ketersediaan × performa × kualitas. |
| **Variance** | Selisih antara biaya standar dan biaya aktual (material, tenaga kerja, overhead). |
| **Standard Cost** | Harga pokok yang ditetapkan di muka dan dipakai sebagai pembanding aktual. |

## Assets and Project

| Istilah | Definisi |
|---|---|
| **Capitalization** | Pengakuan pengeluaran sebagai aset, bukan beban, karena memberi manfaat lebih dari satu periode. |
| **Residual Value** | Estimasi nilai sisa aset pada akhir masa manfaat. |
| **Componentization** | Pemisahan satu aset menjadi komponen dengan umur dan penyusutan sendiri. |
| **Impairment** | Penurunan nilai aset ketika jumlah terpulihkan lebih rendah dari nilai tercatat (IAS 36). |
| **Revaluation** | Penilaian kembali aset ke nilai wajar (IAS 16 model revaluasi). |
| **Milestone Billing** | Penagihan berdasarkan tahapan yang disepakati, bukan berdasarkan waktu. |

## Software and Implementation

| Istilah | Definisi |
|---|---|
| **Master Data** | Data relatif stabil yang dipakai transaksi (item, vendor, pelanggan, COA). |
| **Posting** | Tindakan mencatat transaksi ke buku besar. |
| **Posting Profile** | Aturan yang memetakan transaksi modul ke akun GL. |
| **Fit-Gap** | Analisis kesesuaian proses bisnis dengan kemampuan sistem dan celah yang perlu ditangani. |
| **UAT** | User Acceptance Test; pengujian oleh pengguna sebelum go-live. |
| **Cutover** | Perpindahan dari sistem lama ke sistem baru, termasuk migrasi saldo. |
| **Intercompany** | Transaksi antar entitas dalam satu grup yang harus dieliminasi saat konsolidasi. |
