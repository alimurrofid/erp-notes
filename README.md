# ERP Notes

## AI Agent

`AGENTS.md` adalah entry point untuk AI agent: non-negotiables, routing per tugas, dan definition of done.

Detail berada di:

- `.agents/rules/` — aturan per domain (domain, accounting, tax-id, content-format, writing-style)
- `.agents/skills/` — prosedur (erp-article, erp-review, accounting-validation, research-citation, erp-integration-analysis)
- `.agents/workflows/` — alur kerja (create, revise, verify, maintain)
- `.agents/references/scenario-register.md` — angka dan nomor dokumen kanonik
- `.agents/sources.md`, `.agents/terminology.md`, `.agents/document-template.md` — referensi
- `.agents/scripts/` — pemeriksaan deterministik

```bash
npm run check:content
npx quartz build
```

## Development & Deployment (Quartz v4)

Knowledge base ini dipublikasikan menggunakan [Quartz v4](https://quartz.jzhao.xyz/) yang kompatibel dengan Obsidian dan dideploy secara otomatis ke GitHub Pages.

### Menjalankan Secara Lokal

```bash
# Install dependencies
npm install

# Jalankan local development server dengan live preview
npx quartz build --serve
# atau: npm run serve
```

Buka `http://localhost:8080` pada browser.

### Menjalankan Build

```bash
npx quartz build
# atau: npm run build
```

Hasil build statis akan disimpan di folder `public/`.

### Deployment ke GitHub Pages

Deployment dijalankan otomatis melalui GitHub Actions workflow (`.github/workflows/deploy.yml`) setiap ada `push` ke branch `main`.

Pengaturan awal di repository GitHub:
1. Buka tab **Settings** > **Pages**.
2. Pada bagian **Build and deployment** > **Source**, pilih **GitHub Actions**.
